# Upstream artwork source

These original VIVI Music Wrapped cover files are retained as attributed source artwork for `scripts/generate_tinium_assets.py`. They are not packaged as Tinium branding. The generator preserves the original lower artwork and replaces the old wordmark band with the exact supplied Tinium logo.

The upstream project's GPL license and author attribution remain unchanged. The official Tinium source is `branding/Tinium Logo.png`; it must not be edited or redrawn by the generator.
