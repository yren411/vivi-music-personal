Tinium 6.0.8 Beta 2

What's New

- Replaced the original VIVI Music updater with a GitHub Releases-based update checker.
- Added direct APK download links through the browser.
- Improved version detection for stable and beta releases.
- Updated the update screen to display Tinium version information.
- Improved error handling and update-check reliability.

Notes

- This is a beta testing build.
- Updates are detected from published Tinium GitHub Releases.
- Unpublished test builds do not appear as available updates.
