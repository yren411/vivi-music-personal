# Branding and historical reference

`bannerofficial.png` and `ic_launcher-playstore.png` are derived from the official Tinium source logo. The latter is an asset only; no release or store publishing workflow is configured.

`banner.png` is an archived screenshot of the upstream VIVI Music website. Upstream screenshots in `NEW-UI`, `SCREENSHOTS`, and Fastlane screenshot directories are also historical references, not screenshots of the current Tinium build. They remain unchanged to avoid fabricating UI verification.
